# 利用ガイド

「とけいのれんしゅう」は、小学2年生がアナログ時計の読み方と、「〜分後」「〜分前」「何分間」の計算を学ぶためのアプリです。針が実際に動き、動いた分が色のついた帯・数直線・ブロックとして見えるので、「60分で1時間くり上がる」ことを量として理解できます。

## 画面の構成

| 画面 | 使う人 | できること |
|---|---|---|
| まなぶ | 子ども・保護者 | 時計を自由に動かして、動いた量を見る。説明用のデモにも |
| れんしゅう | 子ども | 10問セットで出題。答えたあとに動きの解説を見る |
| プリント | 保護者・先生 | A4のテストを作って印刷・PDF保存。解答ページ付き |
| せってい | 保護者 | ふりがな、午前・午後、解説の方式、フォントなど。れんしゅうの記録も見られる |

## まなぶ

PCなど横長の画面では、左に大きな時計、右に操作ボタンと動きの表示が並びます。スマートフォンでは上から順に並びます。

1. 「+1分」「+5分」「+10分」「+30分」「+60分」を押すと針が進みます。「−」のボタンで戻ります。
2. 時計の下のデジタル時計は針に合わせて1分ずつ変わります。時は赤、分は青です。
3. 「すすんだ時間」のカウンターが0から数え上がり、60分を超えると「= 1時間20分」のように分解が出ます。
4. 時計の帯（青）は動いた範囲です。60分で1周し、次の周は内側の帯に移ります。12を通るときは12が光り、時の数字が変わります。
5. 数直線とブロックは、同じ量を直線と塊で表したものです。
6. 式は「くぎって かんがえる」（4時ちょうどで区切る、教科書の方法）と「1時間の かたまりで かんがえる」（80分 = 1時間 + 20分）を切り替えられます。
7. 針を指でドラッグして好きな時刻に合わせることもできます（1分きざみ）。
8. 再生バーをドラッグすると、途中の状態を止めて見られます。「はやさ」で速度を変えられます。

### じこくを きめて うごかす（せんせいモード）

ボタンの下の「じこくを きめて うごかす（せんせいモード）」を開くと、手元のテストと同じ条件をそのまま再現できます。子どもに教えるときや、問題を一緒に確かめるときに使います。

1. 「1. じこくを きめる」でテンキーから時刻を入れ、「この じこくに する」を押すと、針がその時刻に一度で移ります（アニメーションなし）。午前・午後の設定が入のときは、先に午前か午後を選びます。
2. 「2. 分すうを きめて うごかす」で「すすむ（〜分後）」か「もどる（〜分前）」を選び、分すうを入れて「うごかす」を押すと、その分だけ針が動きます。
3. 分すうは60分より大きい数（90分、145分など）も入れられます。動いた量は帯・数直線・ブロック・式にそのまま出ます。
4. テンキーは、その欄に入らない数字を押すと次の欄へ送られます。7時5分は「7 → 0 → 5」と押せます。

## れんしゅう

1. 「むずかしさ」（★1〜★4）と「もんだいの しゅるい」を選びます。★を変えると、そのレベルにある種類だけが選べます。
2. 「こたえかた」は3種類です。
   - 4つから えらぶ：選択肢を押します。まちがいの選択肢は「くり上がりを忘れた」など、よくあるまちがいから作られています。
   - はりを うごかす：長い針をドラッグして答えの時刻に合わせ、「こたえる」を押します。
   - かずを いれる：テンキーで時・分を入力します。
3. 「ヒントを みる」は3段階です。向き → 区切りの時刻 → 途中まで針が動く、の順に出ます。ヒントを使っても正解扱いです。
4. 答えると、正解でもまちがいでも動きの解説が再生されます。まちがえたときは「おしい。もういちど みてみよう」と出ます。×や赤は使いません。
5. 10問終わると結果が出ます。まちがえた問題は「うごきを みる」でもう一度解説を見られます。
6. 結果は端末（ブラウザ）の中に保存され、「せってい」の「きろく」で見られます。サーバーには送りません。

### 難易度の目安

| ★ | 分のきざみ | 動く量 | 種類 |
|---|---|---|---|
| ★1 やさしい | 15分 | 30分まで | よむ、かく、〜分後（くり上がりなし） |
| ★2 ふつう | 5分 | 60分まで | ＋ くり上がりあり、〜分前 |
| ★3 むずかしい | 5分 | 120分まで | ＋ 〜時間後、何分間、午前・午後 |
| ★4 はってん | 1分 | 180分まで | ＋ 時間と分の変換、文章題 |

## プリント

1. むずかしさ・種類・問題数（6 / 8 / 10問）・枚数・出力（問題のみ / 答えのみ / 両方）を選び、「つくる」を押します。
2. プレビューを確認して「いんさつ / PDF」を押すと、ブラウザの印刷ダイアログが開きます。用紙はA4縦です。
3. 答えのページでは、答えが赤字で入り、動いた範囲がグレーの帯で印刷されます。
4. 「つくる」のたびに新しい問題になります。同じ問題をもう一度印刷したいときは、そのときのURL（`seed=` を含む）を開いてください。

印刷のコツ：印刷ダイアログで「背景のグラフィック」をオンにすると、帯や色がきれいに出ます。

## せってい

- ふりがな：問題文の漢字にふりがなを付けます。
- 午前・午後：時刻に「午前」「午後」を付けます。教科書に合わせ、正午は「午後0時」と表示します。
- 解説の方式・こたえかた・はやさ：れんしゅうの初期値です。
- うごきを へらす：アニメーションを10分ごとのコマ送りにします。OSの「視差効果を減らす」設定に合わせることもできます。
- フォント：BIZ UDPゴシック（既定）、M PLUS 1p、Klee One から選べます。
- はってん：ホームの時計に秒針を出す、24時間表示（15:10）にする。3年生以上向けです。

## よくある質問

**オフラインでも使えますか？** 一度開けば、ネットワークがなくても「まなぶ」「れんしゅう」「プリント」が動きます（PWA）。

**記録はどこに保存されますか？** ブラウザの localStorage です。端末を変えると引き継がれません。「せってい」から消せます。

**iPadで針をドラッグできますか？** できます。指で長い針を動かしてください。
